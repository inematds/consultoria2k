# 🧭 Consultor de IA — Do Rótulo ao Resultado

Formação prática (formato INEMA.CLUB) para profissionais que querem atuar como **consultores de IA** em empresas.

> O trabalho do consultor não mudou: entrar na empresa, achar a **restrição real** e prescrever a
> solução mais simples que funciona. A IA é a **caixa de ferramentas**, não a descrição do cargo.

## A pirâmide de soluções

- **Base** — workflows determinísticos (sem IA): baratos, rápidos, confiáveis.
- **Meio** — workflows com IA: mais poder, mais custo, mais pontos de falha.
- **Topo** — agentes de IA: capacidade e risco máximos, maior tempo de entrega.

Comece pela base. Suba só quando o problema realmente exigir.
